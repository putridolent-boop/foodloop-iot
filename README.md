# FoodLoop - Smart Food Waste Management

## About
FoodLoop is an IoT-based system designed to reduce food waste by connecting food sellers with consumers through discounted surplus food sales.

Unsold organic food that is suitable for composting can be recorded and allocated to farmers or compost managers.

## Objectives
- Reduce food waste.
- Provide affordable surplus food.
- Monitor food storage temperature.
- Support organic waste management.

## Technologies
- Python
- MQTT
- HTML, CSS, JavaScript
- IoT Temperature Sensor
